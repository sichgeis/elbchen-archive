# Screencast capture plan

Capture the final public product before DNS cutover. Use a 1440×900 browser
window and neutral public data. Target length: three to five minutes.

## Storyboard

1. **Context — 20 seconds**
   - Open `foerderwerk.org`.
   - Introduce the aim: digital tools for NGOs and funding research.
2. **Product family — 35 seconds**
   - Scroll through the research tools and KI workplace.
   - Avoid prices, newsletter forms and personal contact forms.
3. **Stiftungskartei entry — 35 seconds**
   - Open `kartei.foerderwerk.org`.
   - Show the three modes: KI, direct and professional search.
4. **Representative search — 60 seconds**
   - Use the neutral term `Heiliggeist` in direct search.
   - Show result cards, topic tags, target groups and project summaries.
5. **Foundation profile — 60 seconds**
   - Open `Bürgerliche Heiliggeist-Stiftung Passau`.
   - Show themes, target group, projects and source sections.
6. **How it worked — 40 seconds**
   - Cut to the architecture section in the static case study.
   - Explain Nuxt, FastAPI, Postgres and vector matching.
7. **Closing — 20 seconds**
   - Return to the project archive.
   - State that the service has ended and the work remains documented.

## Capture rules

- Do not show Portainer, server consoles, API credentials or browser profiles.
- Do not use real user accounts, conversations, subscriptions or outreach data.
- Disable notifications and unrelated browser tabs.
- Record narration separately if live narration makes the demonstration less
  controlled.
- Export one original-quality MP4 and a compressed web version.
